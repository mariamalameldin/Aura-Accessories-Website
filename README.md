# Aura – Accessories Brand Website ✨

Aura is a frontend web project for an accessories brand that offers stylish collections for both women and men.

The website presents a clean and modern UI where users can explore the brand and easily access its social media platforms.

## 🔹 Project Features
- Responsive accessories brand landing page
- Separate sections for men and women accessories
- Social media icons linked to:
  - Instagram
  - Facebook
  - TikTok
- Search bar (UI only – not activated)
- Clean and simple user interface

## 🔹 Technologies Used
- HTML5
- CSS3
- JavaScript (basic interactions and inline scripts)

## 🔹 Project Purpose
This project was developed as the **final project** for the ITI course:

**Introduction to Web Technologies (Frontend)**

It focuses on applying core frontend concepts and building a complete static website using HTML, CSS, and JavaScript.
